# Фінальний проєкт: Будинок з привидами (Three.js)

Розширена версія міні-проєкту «Haunted House».

## Запуск

``` bash
npm install      # лише перший раз
npm run dev      # локальний сервер
npm run build    # збірка у папку dist/
```

## Обов'язкові вимоги

| Вимога | Де в `src/script.js` |
|---|---|
| Створення геометрії | Box, Cone, Plane, Sphere, Cylinder (призма даху сараю), Dodecahedron (каміння), Ring, Shape (крила кажанів), InstancedMesh (паркан) |
| Імпорт текстур | `TextureLoader`, текстури Poly Haven у форматі **WebP** (підлога, стіни, дах, кущі, могили, двері) + `CanvasTexture` для таблички |
| Створення матеріалів | `MeshStandardMaterial` з map / aoMap / roughness / metalness / normal / displacement / alpha, `MeshBasicMaterial`, емісивні вікна |
| Освітлення | Ambient, Directional (місяць), PointLight біля дверей, 3 PointLight-привиди, світло блискавки; тіні PCFSoft |
| Анімація | Привиди, миготіння ліхтаря біля дверей, мерехтіння вікон, кажани з крилами, що махають, блискавки |
| Небо | `Sky` з налаштуваннями (turbidity, rayleigh, mie, elevation, azimuth) + місяць |
| Туман | `FogExp2` з налаштуванням кольору та щільності |

## Доповнення

- Сарай/гараж із дощатими воротами, туалет на задньому дворі (з місяцем на дверях), димар.
- Паркан із хвірткою, кам'яна доріжка, табличка «Обережно! Тут живуть привиди», каміння, сухі дерева (рекурсивно згенеровані гілки).
- Могили і хрести, що не з'являються на будинку, доріжці та інших об'єктах.
- Вікна з рамами й теплим світлом.
- Звуки (Web Audio API, без файлів): вітер, грім після блискавки, «шепіт» привидів, що гучнішає, коли привид поруч із камерою.
- Панель налаштувань (lil-gui): світло, кольори, привиди (швидкість, інтенсивність, радіус, кольори), небо, туман, повторення текстур, displacement, блискавки, кажани, гучність.
